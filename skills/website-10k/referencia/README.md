# Código de referência

Código real de uma LP construída com este método. O guia de uso, o que cada arquivo faz e o que trocar ao adaptar estão em `../references/padrao.md`.

Ao copiar para uma LP: troque as cores fixas do `cena.css` pelos tokens da marca, e os textos, mídias e traços do logo do `sections/TopoExemplo.tsx`.
