# Para a IA que abriu este repositório

Este repositório é a skill **website-10k**: o método para criar landing pages de nível agência com IA.

- **Para criar uma LP:** leia `skills/website-10k/SKILL.md` inteiro e siga o que ele manda ler antes da primeira resposta. Nunca construa a LP dentro deste repositório: cada LP ganha o próprio repositório (`lp-<marca>`), criado na Fase 0.
- **Para melhorar a skill:** lições que valem para todas as LPs entram em `skills/website-10k/references/` (troubleshooting, padrão, processo) ou no `template/`, num commit próprio. O que é de uma LP só fica no repositório dela. Nunca coloque tokens, contas, e-mails ou dados de clientes aqui.
